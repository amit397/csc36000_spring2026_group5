# Week 02: gRPC Migration

Migration of the distributed prime-number system from HTTP/JSON to gRPC + Protocol Buffers.

## Quick Start

### 1. Install Dependencies
```powershell
python -m pip install grpcio grpcio-tools protobuf
```

### 2. Generate Protobuf Code (if needed)
```powershell
cd week02
python -m grpc_tools.protoc -I./proto --python_out=. --grpc_python_out=. ./proto/primes.proto
```

### 3. Run Coordinator 
```powershell
python primary_node.py --host 127.0.0.1 --port 9300 
```

### 4. Run Worker Node
```powershell
# Standalone (no coordinator)
python secondary_node.py --port 9100

# With coordinator registration 
python secondary_node.py --port 9100 --primary 127.0.0.1:9300

# With coordinator registration && node-id specified

python secondary_node.py --port 9100 --primary 127.0.0.1:9300 --node-id worker1
```
### 5. Run primes_cli
```powershell
python primes_cli.py --exec distributed --primary 127.0.0.1:9300 --low 1 --high 5000000 --mode count --include-per-node --time
```



### 6. Run Tests (Skip steps 3, 4, 5 and do this alone)
```powershell

# Run tests in powershell
python test_grpc_worker.py
```

## New Files Detail

### 1. `proto/primes.proto`

The protobuf schema defining all messages and services for the system.

**Enums** (strongly-typed, replaces string values):
```protobuf
enum Mode {
  COUNT = 0;  // Count primes only
  LIST = 1;   // Return list of primes
}

enum ExecMode {
  SINGLE = 0;    // Single-threaded
  THREADS = 1;   // Thread pool
  PROCESSES = 2; // Process pool
}
```

**Key Messages**:

| Message | Purpose | Fields |
|---------|---------|--------|
| `NodeInfo` | Worker node metadata | node_id, host, port, cpu_count, timestamps |
| `RegisterNodeRequest` | Registration payload | node_id, host, port, cpu_count, timestamp |
| `RegisterNodeResponse` | Registration result | ok, node, error |
| `ListNodesRequest` | Query active nodes | (empty) |
| `ListNodesResponse` | Node list | ok, nodes[], ttl_seconds |
| `HealthRequest` | Health check | (empty) |
| `HealthResponse` | Health status | ok, status, node_id |
| `ComputeRequest` | Compute parameters | low, high, mode, chunk, exec_mode, workers, max_return_primes, include_per_node/chunk |
| `ComputeResponse` | Compute results | ok, total_primes, max_prime, primes[], timing, per_node[] |
| `PerNodeResult` | Per-node breakdown | node info, slice, timing, primes |

**Services**:

```protobuf
service CoordinatorService {
  rpc RegisterNode(RegisterNodeRequest) returns (RegisterNodeResponse);
  rpc ListNodes(ListNodesRequest) returns (ListNodesResponse);
  rpc Compute(ComputeRequest) returns (ComputeResponse);
}

service WorkerService {
  rpc ComputeRange(ComputeRequest) returns (ComputeResponse);
  rpc Health(HealthRequest) returns (HealthResponse);
}
```

## API Mapping: HTTP → gRPC

| Week01 HTTP | Week02 gRPC | Notes |
|-------------|-------------|-------|
| `GET /health` | `WorkerService.Health()` | Returns `HealthResponse` |
| `POST /compute` with JSON body | `WorkerService.ComputeRange()` | Takes `ComputeRequest`, returns `ComputeResponse` |
| `POST /register` (called by worker) | `CoordinatorService.RegisterNode()` | Worker calls coordinator |
| `GET /nodes` | `CoordinatorService.ListNodes()` | To be implemented in Task 3 |
| `POST /compute` (on coordinator) | `CoordinatorService.Compute()` | To be implemented in Task 3 |
